# Blinded Evaluation Contract v2

## Endpoints

- E1 Formulation, primary: blinded P1 quality.
- E2 Propagation: whether P1 requirements survive into specification,
  implementation, execution, results, and paper.
- E3 Outcome, secondary: final model correctness, fit, validation, and report quality.
- Cost, secondary: calls, elapsed time, and tokens when available.

Missing token telemetry remains missing.

## Freeze Before Runs

```powershell
python -m qdm.evaluation.protocol_v2 init-protocol `
  --output <evaluation-root>/protocol.json --expected-judges 2
```

Do not edit this file after creation. Its canonical hash binds every packet and score.

## Prepare and Judge a Pair

```powershell
python -m qdm.evaluation.protocol_v2 prepare-pair `
  --protocol <evaluation-root>/protocol.json `
  --run-a <complete-run-1> --run-b <complete-run-2> `
  --output <evaluation-root>/pairs/<pair-id> `
  --pair-id <pair-id> --problem-id <problem-id> `
  --replicate-id <seed-or-replicate> --seed <blinding-seed>

python -m qdm.evaluation.protocol_v2 score-template `
  --protocol <protocol.json> --pair-dir <pair-dir> `
  --endpoint formulation --judge-id <judge-id> --output <score.json>

python -m qdm.evaluation.protocol_v2 freeze-score `
  --protocol <protocol.json> --pair-dir <pair-dir> --score <score.json>
```

Preparation fails unless the pair is one `qdm_full` and one `mm_agent_native`
run with identical P0. Public P1 and P2 packets use anonymous labels A/B. The
method mapping and redaction log remain private. Every score must cite a JSON
pointer and exact packet quote. Judges must not share context or scores.

Include both completed and explicitly stopped runs. Missing P1/P2 artifacts and
failed integrity checks appear in the anonymous packets and are scored as
outcomes; they are not silently excluded. Reject only P0 mismatch,
cross-condition contamination, or a run that has not reached a terminal state.

Only after both endpoints have the required number of distinct judges:

```powershell
python -m qdm.evaluation.protocol_v2 reveal `
  --protocol <protocol.json> --pair-dir <pair-dir>
```

## Propagation Attribution

```text
not discovered in P1              -> elicitation_failure
discovered but lost downstream    -> specification_retention_failure
retained but code is wrong        -> implementation_failure
execution/results unsupported     -> result_validation_failure
paper exceeds supported results   -> writing_overclaim
hash/provenance failure           -> integrity_issue
otherwise                         -> none
```

An implementation is met only when the relevant code parses, the feature is
invoked by the executed path, execution succeeds, and results contain evidence.

## Statistical Unit

Average judges within submission, then seed replicates within problem. Paired
comparisons and bootstrap resampling operate on problems only. Questions,
calls, requirements, seeds, and judge items are not independent `n`.
